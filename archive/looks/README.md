# Archived Looks (not built)

Cyberpunk, Matrix, and MAGI were optional Android paint. They are frozen here
and are not compiled. Live VC Port keeps **Original** (the VeraCrypt-like Desktop
look) and **Dark mode** (the old Signal look, advertised as Dark mode; enum name
`Signal` stays so on-device prefs still load).

**Nothing here is compiled.**

| What | Where |
| --- | --- |
| Full theme at archive time | `VcPortTheme.kt` |
| Rajdhani / VT323 / Oswald | `font/` (IBM Plex stays in the live app) |
| MAGI / Unit-01 picker icons | `drawable/` |
| Emulator shots | `screenshots/` |
